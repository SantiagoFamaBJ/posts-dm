# Posts DM

Generador de posteos de productos para revendedores de Dental Medrano.

- `/{link-del-revendedor}` → editor de posteos (cada revendedor tiene su link)
- `/ADMIN` → productos, importador desde dentalmedrano.com.ar, marcas, revendedores y estadísticas

Stack: Next.js + TypeScript + Tailwind, Supabase (tablas `posts_`, bucket `posts`), Vercel.

Variables de entorno: ver `.env.example`.
